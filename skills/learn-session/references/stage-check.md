# Stage check: `teach` or `learn-session`?

Retrieval practice needs something to retrieve. The test is cheap and it runs before the role arc.

## The three-sentence test

Ask the user: "Say three true sentences about <subtopic>, in your own words, without looking."

- **Three true sentences come out** -> this is a `learn-session`. Guidance would be re-reading, and re-reading feels like progress while producing none.
- **Fewer than three, or three sentences that are wrong** -> hand off to `teach` for one guided, cited lesson on exactly that subtopic, then run the session on it cold, in the same sitting if there is time.
- **The user half-knows it** -> still a `learn-session`. Half-knowing is the best state for retrieval; do not spend the slot on a lesson.

## What each stage owes

| | `teach` | `learn-session` |
|---|---|---|
| Starts from | nothing reliable in memory | something, however shaky |
| Produces | one cited lesson + a printable reference, in the topic folder | attempts, graded, with every gap named |
| Done when | the user can state the problem it solves and the main rule | the user passed cold: right, in clear English, at confidence 3 |
| Evidence for a level change | never | yes, when shown alone |

## Do not

- Use `teach` to avoid a hard question. Being stuck is the work.
- Use `learn-session` on a blank slate: an hour of guessing at something never seen teaches the guessing, not the thing.
- Skip logging. `session-log` closes both stages.
